# Results

## Included now

### Voyager spectrum

The `voyager/` folder contains the finalized empirical proton-spectrum figures and the spectrum-validation figure.

### Geant4 source validation

The `geant4/` folder currently contains **source-sampling validation only**.

The 500,000-draw validation checks:

- energy-bin probabilities,
- the isotropic plane-crossing angular distribution,
- reproducibility of the Voyager-derived primary source.
